# AI-Powered Chatbot Development for Customer Support Automation

## Project Information
Unit: ITSU2006 – IT Project Management
Group: 16 Sydney
Organisation: HarbourCart (fictional)

## Project Overview
This project proposes an AI-powered chatbot to automate customer support for an Australian e-commerce company.

## Objectives
- Answer customer enquiries 24/7.
- Provide information about orders, deliveries, products and returns.
- Escalate complex enquiries to human support staff.
- Protect customer privacy and security.

## Schedule
12 weeks: 2 November 2026 to 24 January 2027.
